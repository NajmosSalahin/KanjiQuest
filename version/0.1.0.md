## What was built

- **Monorepo tooling** — npm workspaces (`client`, `server`, `shared`), ESLint flat config, Prettier, Husky hooks (pre-commit lint-staged, pre-push `npm test`).
- **`shared/`** — domain constants (SRS intervals, XP curve, level thresholds, store catalog) and JSDoc typedefs used by both sides.
- **`server/`** — Express ESM scaffold: root `.env` loading, health route, JSON error envelope (Zod-validated error middleware), vitest + supertest test setup.
- **`client/`** — Vite + React scaffold, design tokens (`tokens.css` from the spec's §3 token table), reusable UI primitives, `/kitchen-sink` component gallery for visual verification.
- **Docs** — `.env.example`, `README.md`, `CONTRIBUTING.md`, `DECISIONS.md` (kickoff Q&A, D1–D5, CSRF approach), `IMPLEMENTATION_PLAN.md`.

## Decisions in this version

- **D1–D5** (owner-approved): no Docker for local dev; MongoDB via local `mongod` for development and Atlas in production; avatars on local disk behind a storage adapter; Google OAuth removed (email+password only); stroke animation timings 600 ms / 300 ms per stroke at 1× (1,200 / 600 at 0.5×), **0.5× default**.
- **CSRF** — double-submit cookie token approach (documented per spec §14).
