## What was built

- **Store catalogue + API (§6.11 / §7.10 / §9):** eight server-priced items — Streak freeze (50 coins, max 2), XP boost (100, 1.5× for 24h), titles The Diligent (25) / Kokoro no Tsuchi (50) / Yama no Ue (75), and frames Sakura / Take / Tsuki (100 each). `GET /store/items` returns live ownership, equip, active, cap, affordability, and `disabledReason` state; `GET /store/inventory` lists owned items.
- **Atomic purchases + effects (D17):** `POST /gamification/store/purchase` validates catalogue/caps/ownership/balance, deducts coins with the balance in the update filter, and records `UserInventory`. Freezes increment the profile counter, an active boost extends from `max(now, expiry)` by 24h, and cosmetics are permanent. A failed follow-up write compensates the deduction (the test database is standalone). Errors: `400 INSUFFICIENT_COINS`, `409 ALREADY_OWNED` / `MAX_FREEZES`, `404 ITEM_NOT_FOUND`.
- **Equip API:** `POST /gamification/store/equip` accepts `{slot: 'title'|'frame', itemId|null}`, checks ownership, and stores the item id on `equippedTitle` / `equippedFrame`; frames render as custom line-art rings around the existing avatar.
- **`/store` screen (§7.10):** responsive catalogue cards with custom icons, coin balance, Equipped/Owned/Active/Full badges, held-freeze count, boost expiry copy, insufficient-funds hints, purchase confirmation modal with resulting balance, equip/unequip actions, toasts, and auth-store coin/inventory merge.
- **Weekly XP + leaderboards (D18 / D19):** `weeklyXP` counts every XP source (reviews, quiz, sprint, quests, sweep, goal bonus, achievements) and lazily rolls to 0 at **Monday 00:00 UTC** on each award/read; undo only subtracts inside the award week. `GET /leaderboard?period=weekly|allTime` aggregates live: XP descending, **competition ranks for ties**, deterministic display tie-break (`createdAt`, `_id`), top **100**, and a sticky current-user row (rank = count of higher XP; zero-XP users excluded from top entries).
- **`/leaderboard` screen (§7.9):** Weekly / All-time tabs, ranked table with avatar frames, equipped titles, XP, “You” treatment, podium styling for the top three, sticky current-user row, skeletons, and a specific empty state when nobody has earned weekly XP.
- **Dashboard mini-board (§7.1):** “This week” top five with rank, 28px frame-aware avatars, name + equipped title, XP, highlighted current-user row, and a “Full leaderboard →” link. The daily-goal ring now also merges the new profile fields.
- **`/profile` with three tabs (§7.8 / §6.13):** identity card (128px avatar with equipped frame, level shield, joined date), stat cards (total XP, longest streak, kanji mastered), inline display-name edit, **title picker** backed by inventory, full **achievements grid** with locked progress and a detail modal, and **auto-saving settings** for theme, daily goal, daily review limit, furigana, sound, haptics, reminder time, JLPT level, and timezone. Includes logout and typed-name **account deletion** with a hard cascade.
- **Avatar upload (D17 / §6.13):** multipart upload validated server-side (JPEG/PNG/WebP magic bytes, 2 MB cap). The storage adapter writes to `server/uploads/` in dev/test and to the Mongo `avatarAssets` collection in production, served from public immutable `GET /api/v1/assets/:id`; replacing or deleting an avatar removes the old bytes. `DELETE /users/me/avatar` returns to initials.
- **Theme bootstrap (§6.13):** auto/light/dark preference resolves before React hydration from a cached `localStorage` value, follows OS changes while set to auto, and persists through the settings auto-save.
- **Navigation:** app-shell menu now exposes Profile, Store, Leaderboard, and Settings (settings deep-links to `/profile?tab=settings`); `/settings` redirects there.
- **Data:** new `AvatarAsset` and `UserInventory` models; `GamificationProfile` gains `weeklyXP`, `weeklyXPWeek`, `streakFreezesUsed`, `equippedFrame`; freeze achievement (`Mamori`) is now active. `scripts/migrate-080.js` creates leaderboard/inventory/avatar indexes, initializes the new fields, and mirrors existing freeze counts into inventory.

## Decisions applied

- **D17** — avatar storage adapter (disk in dev/test, Mongo assets in production, immutable public URLs) and the fixed catalogue/effects, including boost extension from the current expiry.
- **D18** — weekly XP includes every XP source, lazily resets Monday 00:00 UTC, purchases award none, cross-week undo is isolated, and v0.8.0 starts the live week at zero.
- **D19** — live leaderboard aggregation (no cache collection), competition ranks, deterministic tie display, top 100 + sticky row, zero-XP exclusion.
- Open question **#3** (quest-title wording) and **#4** (password reset) remain open; #4 is needed before Phase 8 settings/polish.
