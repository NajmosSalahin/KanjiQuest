## What was built

- **Server auth (spec §14)** — `User` model; bcrypt cost 12; 15-minute access JWT (httpOnly, Secure, SameSite=Strict); 7-day refresh tokens, rotated on use, stored **hashed**, with **reuse detection** (beyond the spec minimum); CSRF double-submit on state-changing routes; rate limits on auth endpoints; Zod validation on every input; endpoints `register`, `login`, `refresh`, `logout`, `GET /users/me`.
- **Client auth** — API client with **silent single-flight refresh** (one refresh shared across concurrent 401s), auth store, Zod + custom `zodResolver`, app shell chrome (header/footer), route guards, `Login` / `Register` screens per §7.11 copy — **no Google button** (D2).
- **Hardening** — pre-commit hook rejects `.env`, `*.pem`, `*.key`, `*secret*` files (14 patterns).
