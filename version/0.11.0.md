## What was built

- **Container stack (D27):** a root multi-stage `Dockerfile` with `api` and
  `client` targets — Node 22/bookworm for the API, nginx/alpine for the static
  SPA. `docker-compose.yml` runs both on <http://localhost:8080> and reads
  MongoDB from `MONGODB_URI`; there is no `mongo` service (D1). `node:22`
  dependencies are installed once from the workspace lockfile, the client is
  built in its own stage, and `.dockerignore` keeps `node_modules`, builds,
  seed caches, uploads, and `.env` out of the context.
- **nginx parity (`deploy/nginx.conf`):** serves the SPA with an
  `index.html` fallback, proxies `/api/`, `/uploads/`, and `/health` to the API
  service for same-origin cookies, mirrors the Vercel security headers,
  caches hashed assets immutably, revalidates `sw.js`, and allows the 2 MB
  avatar upload.
- **Logger hardening:** `pino-pretty` is a devDependency, so the logger now
  checks it is resolvable and falls back to plain pino instead of crashing a
  production-only image running with `NODE_ENV=development`.
- **`DEPLOY.md`:** Render Blueprint runbook (service settings, dashboard-only
  secrets, auto-deploy verification), Railway/manual parity, Vercel CLI-only
  client deploys with the Git integration kept off, seeding and migration
  order, Brevo password reset, Docker usage, post-deploy smoke, and a
  troubleshooting table.
- **`ARCHITECTURE.md`:** Mermaid topology, request lifecycle, API surface,
  MongoDB collections, SRS/gamification/quest/quiz/stat logic, offline review
  sync, security controls, environment matrix, seed pipeline, and the test
  strategy.
- **Final `README.md`:** status (including the deferred Phase 9 tag), setup
  with the no-Docker local MongoDB helper, exact seed commands and the
  5–15-minute expectation, an explanation of the §5.7 coverage report and why
  partial coverage is expected, tests/lint/smoke, Docker, deployment links,
  the license table, and project layout.
- **License correctness (§5.8):** KANJIDIC2 and JMdict now report **CC BY-SA
  4.0**; KanjiVG stays **CC BY-SA 3.0**. The KanjiVG copyright notice ("KanjiVG
  © Ulrich Apel and contributors, CC BY-SA 3.0.") now appears in the app
  footer as well as on `/licenses`.
- **Release polish:** all four workspace manifests report `0.11.0`;
  `package-lock.json` was refreshed; this note and the changelog were added.
